Общее для диапазона:
- Порядок (42, 47, 45, 46, 44, 43) не менялся, переходы в заметках написаны под него: 41 → разделитель → FINEARTS-HF → FINE-ONE → решение FDA → FIND-CKD → ARTS.

- Плашка-метка раздела «Научные данные: / другие группы пациентов» (708, 24; 216×40, #156082) добавлена на слайды 43–47, заголовок там 660 pt.
